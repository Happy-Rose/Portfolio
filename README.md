# "Portfolio mobile setup" Project

This is a simple mobile-first portfolio setup I built from scratch using HTML and CSS. It puts my navigation bar, short bio, custom background shapes, and social media links all in one clean layout that adapts smoothly between mobile and desktop screens.

## Built With

### Tech Stack

* HTML
* CSS
* Visual Code Editor

### Key Features

* HTML & CSS Basics: Structuring a clean webpage with semantic tags and styling layouts, colors, and spacing from scratch.
* Mobile-First Responsive Design: Adapting the layout smoothly between mobile (375px) and desktop (768px) screens using Flexbox and media queries.
* SVG & Icon Integration: Adding custom SVG background shapes and social media icons with smooth hover effects.

## Getting Started

### Prerequisites

In order to run this project you need

* A Code Editor: A simple editor like VS Code to view or edit the HTML and CSS files.
* Live Server Extension: A VS Code extension used to preview the webpage live in the browser while coding.

### Setup

* Clone this repository to your desired folder
* Open the folder in your code editor (such as VS Code).
* Make sure your HTML file (index.html), CSS file (style.css), and the images folder containing your icons and background graphics are all    kept inside the same project folder.
* Open index.html in your web browser (or launch it with the Live Server extension in VS Code) to view.

### Install

No Installation required for this Project

### Usage

To run the project, execute the following command

* Open index.html in your web browser (or launch it with the Live Server extension in VS Code) to view the portfolio.
* Resize your browser window to see the layout adapt between mobile and desktop views.
* Hover over the navigation links and social media icons to see the interactive effects.
* Edit index.html and style.css in VS Code to customize the bio text, colors, and links.
